# 🎙️ VaaniStock AI

### Speak. Stock. Simplified.

VaaniStock AI is a voice-first multilingual inventory management system designed for small businesses and local retailers. It allows shop owners to manage inventory using natural voice commands in English, Telugu, and Telugu-English mixed language.

## 🚀 Features

- 🎤 Voice-based stock management
- 🌐 English, Telugu & Telugu-English command support
- 📦 Stock In and Stock Out management
- 🔍 Check product stock using voice
- ⚠️ Low-stock and out-of-stock alerts
- 🛒 Reorder suggestions
- 📊 Inventory dashboard
- 🧾 Complete transaction history
- ✍️ Manual inventory management
- 🔊 Optional voice responses
- 📱 Responsive and user-friendly interface

## 💬 Example Voice Commands

- "Rice 5 bags add cheyyi"
- "Sugar 3 kg sold"
- "Oil rendu cartons add cheyyi"
- "Rice stock entha undi?"
- "Low stock items enti?"
- "Em order cheyyali?"

## 🎯 Problem Statement

Small shop owners often depend on notebooks, memory, or repetitive manual data entry to track inventory. This becomes difficult as the number of products and daily transactions increases.

VaaniStock AI simplifies this process by allowing users to update and query inventory through natural voice commands while automatically maintaining stock records, alerts and transaction history.
